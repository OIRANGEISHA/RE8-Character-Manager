# RE8 Character Manager — beta0.9

生化危机 8（Resident Evil Village）人物替换管理器，适用于 Windows x64。

[下载 beta0.9 完整包](https://github.com/OIRANGEISHA/RE8-Character-Manager/releases/tag/beta0.9)

## 功能

- 将剧情伊森替换为夫人长裙模型，覆盖第一人称、官方第三人称、美术造型和佣兵伊森。
- 提供佣兵伊森精简包、佣兵夫人替换，以及剧情夫人本体的原始模型和长裙补丁。
- 一键安装三个人物包；两个伊森包自动互斥。
- 可独立启停夫人呼吸声，支持中文、英语、日语、德语、法语、意大利语、西班牙语、巴西葡萄牙语及俄语，随游戏配音加载。
- 备份已有文件、记录归档变更，并支持停用还原与失败回滚。

## 安装与升级

1. 在 Releases 下载 `RE8CharacterManager_beta0.9.zip`，完整解压到游戏目录以外的固定位置。
2. 退出游戏及其他 mod 管理器，运行 `RE8CharacterManager.exe`。首次使用点“选择目录”，选中包含 `re8.exe` 的游戏目录。
3. 勾选人物或呼吸声，点击“应用勾选项”；“一键全部替换”启用剧情伊森、佣兵夫人、剧情夫人本体，并保留呼吸声勾选。
4. 启动游戏。关闭全部替换时，退出游戏后点击“停用并还原”。

**升级已有安装时，解压覆盖原管理器目录，并保留原来的 `data` 文件夹。** `data` 保存还原记录和备份；启用期间不要删除或替换它。发布包不含任何用户的 `data`。

从本地 v0.8/v0.9 升级会识别原有安装记录及呼吸声选择。启用多语言包后，使用 beta0.9 或兼容的新版本还原；旧版可能不识别新增语音资源。

需要第三人称或佣兵夫人内容时，应已拥有并安装游戏相应的官方内容。第三人称佣兵镜头不包含在本版本。

## 验证与限制

- 已实机确认：修复伊森替换导致的佣兵夫人普通挥爪、蓄力无伤害；一键人物组合下普通挥爪、蓄力和抓取正常。
- 已实机确认英语跑动后呼吸变为正常女声。多语言包的英文文件与该实测版完全一致。
- 其他 8 种配音通过音频解码、文件解析和事件范围检查，尚未逐一实机听音；每个视角、低血量及剧情特殊状态也未完整覆盖。
- 33 项模拟安装、升级、还原、冲突及故障回滚测试通过。测试不改动真实游戏。
- 人物模型仍有测试性质；特殊过场、伤残表现、面部动画与头发物理存在适配限制。
- 本版本不提供独立高跟鞋脚步声包。之前未完成实测的音效试验没有纳入发布。
- 呼吸包保留各语言原始事件结构与其他录音；夫人缺少对应声音的特殊咳嗽等保留伊森原声。

若游戏更新或其他工具改动归档，管理器可能拒绝继续还原。请保留 `data` 与报错，避免同时使用多个工具修改同一资源。

## 从源码构建

需要 Windows、PowerShell 与 .NET Framework 4.x 的 64 位 C# 编译器；构建脚本使用系统自带路径。

```powershell
.\build.ps1
Start-Process .\RE8CharacterManager.exe -ArgumentList '--self-test' -Wait
Get-Content .\test_report.json
```

源码仓库不保存大型模型与音频文件；完整发布包的 `mods` 目录包含本次适配的五个 ZIP。
开发者只做资源兼容性扫描时，可在命令行指定游戏目录运行 `--scan-game`。扫描不安装资源。
